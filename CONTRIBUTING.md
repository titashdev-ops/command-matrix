# Contributing

This is a personal portfolio, not a community product.

Useful pull requests: factual corrections, broken links, accessibility, and build fixes.

Please do not send feature expansions, backend services, or auth/database work. Those are out of scope on purpose.

1. Fork and branch from `main`.
2. `npm install && npm run typecheck && npm run build`.
3. Open a pull request with a short description of the change.
